## What to build

让支委能回答「这次活动谁没来」。

文档要求考勤能区分四种状态：正常签到、请假、缺席、迟到。现在只有签到记录，另外三种无法表达——没有请假的地方可落，缺席也算不出来。

做完之后：支委可以在活动开始前为成员录入请假（含理由、录入人、时间），能修改或撤销；活动结束后统计给出签到名单、缺席名单、请假名单三张表，以及参与率（实到 / 应到）。应到 = 参与范围匹配到的全部成员。迟到由签到时间与签到开始时间自动推导，不需要人工标注。

缺席的定义是：在应到范围内，既没有签到，也没有请假。

## Acceptance criteria

- [ ] 支委能为成员录入请假，含理由，记录录入人与录入时间
- [ ] 支委能修改或撤销已录入的请假
- [ ] 同一成员在同一活动下只能有一条生效中的请假
- [ ] 活动统计返回签到名单、缺席名单、请假名单三张表
- [ ] 缺席名单只包含「在应到范围内且既未签到也未请假」的人，请假的人不出现在缺席名单里
- [ ] 应到人数等于参与范围匹配到的成员总数；活动无参与范围时按全场开放处理
- [ ] 参与率 = 实到 / 应到，应到为 0 时不产生除零错误
- [ ] 考勤状态能区分正常签到与迟到：签到时间晚于签到开始时间即判定为迟到
- [ ] 已请假的人到场签到，签到仍然成功，且统计口径以签到了为准
- [ ] 支委只能为本支部活动录入请假，跨支部被拒绝
