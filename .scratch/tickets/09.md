## What to build

让培养过程产生的材料有地方存：入党申请书、政审材料、培训证书等。

支委可以为成员上传材料并标注类型，上传复用既有的本地文件存储（返回 `file:` 前缀的相对路径，不新开上传通道）。支委能查看某个成员的全部材料列表、删除传错的材料（软删除，不物理删文件引用）。

材料是电子培养档案的素材，因此每条记录必须能回答「这份材料是什么类型、谁传的、什么时候传的」。

## Acceptance criteria

- [ ] 支委能为成员上传材料，支持 PDF、Word、图片、ZIP
- [ ] 上传时必须标注材料类型（入党申请书 / 思想汇报 / 政审材料 / 培训证书 / 其他）
- [ ] 普通成员上传时被拒绝
- [ ] 支委能查看某成员的材料列表，含类型、上传人、上传时间
- [ ] 支委能删除材料，删除后不再出现在列表中，但底层存储与记录不被物理清除
- [ ] 跨支部的支委操作其他支部成员的材料，返回「不存在」
- [ ] 上传走既有的 file: 相对路径约定，不引入第二套存储路径格式
